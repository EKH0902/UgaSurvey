# UgaSurvey

Windows용 C언어 네이티브 설문 제작 GUI입니다. 흰 배경과 검정 글자, 큰 입력 영역으로 구성했습니다. 외부 라이브러리나 인터넷 연결 없이 설문 및 응답을 로컬 JSON 파일에 저장합니다.

## 브라우저 설문 제작기 (GitHub Pages)

`docs` 폴더에 HTML, CSS, JavaScript만으로 동작하는 설문 참여·제작 사이트가 있습니다. GitHub Actions가 설문 파일 목록을 자동 생성하고 GitHub Pages에 배포합니다.

1. 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. 기본 브랜치에 포함된 `.github/workflows/deploy-pages.yml`이 푸시 때 사이트를 배포합니다. 첫 실행이 끝나면 Pages 주소를 엽니다.
4. 저장소가 공개라면 사이트도 공개되므로 개인 정보나 비밀 응답을 입력하지 마세요.

사이트 첫 화면에는 공개 설문 목록과 관리자 로그인 버튼이 표시됩니다. 관리자 로그인 정보는 아이디 `admin`, 비밀번호 `2739`입니다. 로그인하면 설문을 만들 수 있고, 로그인하지 않은 사용자는 공개된 설문에 참여할 수 있습니다. 제작 화면의 설문은 **현재 브라우저의 로컬 저장소에만 저장**되며, JSON 백업을 다운로드해 다른 브라우저에서 불러올 수 있습니다. 질문 이미지는 1.5MB 이하로 첨부할 수 있습니다.

### 공개 설문 게시 방법

1. 사이트에서 관리자 로그인 후 설문을 만들고 `응답용 HTML 만들기`를 누릅니다. `001.html`, `002.html`처럼 번호가 붙은 파일이 다운로드됩니다.
2. 다운로드한 HTML 파일을 저장소의 `docs/surveys` 폴더에 추가하고 기본 브랜치에 푸시합니다.
3. GitHub Actions가 폴더 안의 `001.html` 같은 번호형 HTML을 찾아 설문 목록을 자동 생성하고 Pages에 배포합니다. 별도 목록 파일을 편집하거나 업로드할 필요가 없습니다.

사이트가 Pages에 배포된 뒤에는 설문 HTML 파일만 폴더에 넣고 푸시하면 참여자 목록에 자동으로 나타납니다. 폴더 안 파일명은 `001.html`, `002.html`처럼 숫자 3자리 이상이어야 합니다. 기본 브랜치가 아닌 브랜치의 푸시는 배포하지 않습니다.

**로그인 안내:** `admin / 2739` 화면 잠금은 요청된 기본 흐름을 위한 것으로, GitHub Pages의 정적 파일 안에 로그인 정보가 포함됩니다. 사이트 파일을 볼 수 있는 사람은 로그인 정보를 확인하거나 제작 화면 잠금을 우회할 수 있으므로 실제 보안 인증이 아닙니다. 비공개 설문 제작이 필요하다면 서버 기반 인증을 사용하세요. 공개 저장소에서는 비밀 정보나 민감한 응답을 다루지 마세요.

GitHub Pages는 응답을 제작자 계정으로 자동 전송하거나 중앙 집계하지 않습니다. 응답 제출 시 응답자 기기에 응답 JSON이 다운로드됩니다. 온라인으로 여러 사람의 응답을 수집하려면 별도 서버 또는 데이터베이스 연동이 필요합니다.

## 실행

`build.bat`을 실행하면 Visual Studio C 컴파일러 또는 MSYS2(`D:\msys2`)를 자동으로 사용해 실행 파일을 만듭니다. 기존 `UgaSurvey.exe`가 실행 중이면 파일을 덮어쓰지 않고 `UgaSurvey-updated.exe`라는 새 파일로 빌드합니다. Pretendard 1.3.9 글꼴과 OFL 라이선스 파일도 실행 파일 옆에 복사됩니다. 설문 JSON은 실행 파일과 같은 폴더에 저장됩니다.

## 사용법

1. 처음이라면 `추천 양식으로 시작`을 눌러 예시 설문을 편집하거나, `빈 설문으로 시작`을 눌러 새로 작성합니다.
2. 편집 화면에서 설문 제목과 설명을 입력하고 `+ 문항 추가`로 문항을 만듭니다.
3. 왼쪽 문항 목록에서 순서를 정하고, 오른쪽의 번호가 붙은 단계대로 질문 제목·유형·선택지 및 필수 여부를 설정합니다. `질문 이미지`에서 PNG, JPG, GIF, BMP, TIF 이미지를 첨부하거나 제거할 수 있습니다(이미지당 10MB 이하).
4. `저장하기`를 눌러 보관하고 `미리보기`로 응답자 화면을 확인합니다.
5. 홈 화면에서 설문을 선택한 뒤 `응답 미리보기 / 입력`으로 응답을 작성합니다. `응답 결과 보기` 및 내보내기 메뉴도 사용할 수 있습니다.
6. 응답자를 위한 `HTML`은 Pretendard 글꼴을 포함해 브라우저에서 오프라인으로 열 수 있는 단일 파일입니다. 제출하면 응답 JSON이 해당 기기에 다운로드되며, 제작자에게 자동 전송되지는 않습니다.
7. `응답용 EXE` 내보내기는 실행 파일과 같은 이름의 JSON, Pretendard 글꼴, 글꼴 라이선스 파일을 만듭니다. 이미지가 있는 설문은 `ugasurvey-assets` 폴더도 함께 전달해야 합니다. 응답 화면이 바로 열리고 제출 응답은 옆 JSON에 저장됩니다.

## 현재 동작 범위

- 설문 및 문항 생성, 편집, 삭제, 복제, 순서 이동
- 14가지 문항 유형 선택 및 선택지/설정 입력
- 미리보기, 필수 문항 확인, 응답 저장과 로컬 결과 보기
- JSON 가져오기/백업, 응답 CSV 내보내기, 오프라인 응답 HTML(첨부 이미지를 파일 안에 포함) 및 응답용 EXE+JSON 내보내기, 자동 저장
- 첫 실행용 추천 설문 템플릿과 사용 순서 안내
- Pretendard 1.3.9 글꼴, 파란색 그라데이션 헤더, 흰색 둥근 버튼, 단계별 편집 화면

객관식·체크박스·드롭다운·배율·별점·날짜·시간·숫자는 유형에 맞는 Windows 입력 컨트롤을 사용합니다. 순위형과 그리드형은 현재 텍스트 입력 기반이며, 이미지 선택형은 선택지 목록을 표시합니다. 각 문항에는 선택적으로 질문 이미지를 첨부할 수 있습니다. 앱은 이미지를 실행 파일 옆 `ugasurvey-assets` 폴더에 보관하며, HTML 내보내기는 이를 단일 HTML 파일에 포함합니다. 응답용 EXE는 JSON 및 이미지 폴더와 함께 배포해야 합니다. HTML은 여러 설문 응답을 온라인에서 자동 수집하지 않습니다. EXE 응답을 모으려면 실행 파일과 같은 이름의 JSON 응답 파일을 응답자에게서 회수해야 합니다. 통계 그래프, 문항별 범위 검증, 온라인 응답 수집, 응답 수정은 아직 구현하지 않았습니다. 네이티브 Windows 프로그램이므로 웹/모바일 앱 요구사항은 포함하지 않습니다.
